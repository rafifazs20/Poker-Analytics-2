# Operational Safety Boundary

Poker Analytics 2 is a manual-input local research tool.

Allowed:

- Human-entered cards, stacks, pot sizes, positions, and bet sizes.
- Local CLI or local web UI in future sprints.
- Offline self-play and model training.
- Post-session analysis from logs the user manually provides.

Not allowed:

- Screen capture, OCR, pixel reading, or live poker-client inspection.
- Memory scraping or process inspection of poker software.
- Browser automation or poker-site API integrations.
- Any automated action submission to a poker client.
